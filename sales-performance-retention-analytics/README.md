# 📊 Análise de Performance Comercial, Retenção e Funil de Conversão

Projeto completo de Business Intelligence com foco em análise de vendas, retenção de clientes e eficiência do funil comercial.

---

## 🎯 Objetivo

Transformar dados em insights estratégicos para apoiar a tomada de decisão, identificando:

* Gargalos no funil de conversão
* Impacto do churn na receita
* Oportunidades de crescimento
* Ineficiências operacionais

---

## 🧠 Problema de Negócio

A análise foi construída para responder:

👉 Onde a empresa está perdendo receita?

Principais hipóteses analisadas:

* Alto churn impactando o crescimento
* Baixa conversão de leads
* Dependência de poucos vendedores
* Ineficiências operacionais

---

## 🏗️ Arquitetura do Projeto

Fluxo de dados:

Dados Brutos → SQL Server → Transformação → Modelagem → Power BI

Camadas:

* Staging: dados brutos
* Transformação: limpeza e regras de negócio
* Data Warehouse: modelo estrela
* Visualização: dashboards interativos

---

## ⚙️ Tecnologias Utilizadas

* Power BI
* SQL Server
* DAX
* Modelagem de Dados (Star Schema)
* ETL (Extração, Transformação e Carga)

---

## 📊 Dashboards Desenvolvidos

* Overview Executivo
* Vendas e Operação
* Churn e Retenção
* Funil de Conversão
* Página de Insights Estratégicos

---

## 📈 Principais Métricas

* Faturamento
* Taxa de Conversão
* Churn (%)
* Ticket Médio
* Receita Perdida
* Volume de Leads

---

## 🔍 Principais Insights

* Churn elevado (~79%) impactando diretamente a receita
* Baixa taxa de conversão (~10%), indicando gargalos no funil
* Receita concentrada em poucos vendedores
* Perda significativa de receita ao longo da jornada do cliente

---

## 🚀 Ações Estratégicas

* Implementação de estratégias de retenção (CRM, campanhas, reativação)
* Melhoria na qualidade dos leads
* Otimização do funil de conversão
* Redução da dependência de top performers
* Identificação e correção de gargalos operacionais

---

## 📌 Diferenciais do Projeto

* Pipeline completo de dados
* Análise orientada ao negócio
* Dashboard nível executivo
* Modelagem profissional
* Uso avançado de DAX
